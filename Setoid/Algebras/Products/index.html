    Setoid.Algebras.Products¶

    Products of Setoid Algebras¶

    This is the Setoid.Algebras.Products module of the Agda Universal Algebra Library.

    The product of an indexed family of algebras is formed coordinatewise: its carrier is the dependent function type over the index, its equality is pointwise, and each operation symbol is interpreted by applying the corresponding operation in every factor.

    This module defines that product, ⨅; the machinery for taking the product of a class of algebras rather than of an indexed family; and the one nontrivial fact about products proved here, which is the following:

    The coordinate projections out of a product are surjective when the index type has decidable equality and every factor is nonempty.

    Products are one of the three closure operations H, S, P whose composite V defines a variety, so this module is used throughout Setoid.Varieties.Closure and in the proof of Birkhoff's theorem in Setoid.Varieties.HSP.

    Homomorphisms into and out of a product are in Setoid.Homomorphisms.Products, and ⨅≅ of Setoid.Homomorphisms.Isomorphisms shows that products of isomorphic families are isomorphic.

    {-# OPTIONS --cubical-compatible --exact-split --safe #-}

module Setoid.Algebras.Products where

-- Imports from Agda and the Agda Standard Library --------------------------------
open import Agda.Primitive                         using  () renaming ( Set to Type )
open import Data.Product                           using  ( _,_ ; Σ-syntax )
open import Function                               using  ( flip ; Func )
open import Level                                  using  ( _⊔_ ; Level )
open import Relation.Binary                        using  ( Setoid ; IsEquivalence
                                                          ; Decidable )
open import Relation.Binary.PropositionalEquality  using  ( refl ; _≡_ )
open import Relation.Unary                         using  ( Pred ; _∈_ )
open Func                                          using  ( cong )
                                                   renaming ( to to _⟨$⟩_ )
open Setoid                                        using  ( Carrier ; _≈_ )
                                                   renaming ( isEquivalence to isEqv )
open IsEquivalence                                 using  ()
                                                   renaming  ( refl to reflE
                                                             ; sym to symE
                                                             ; trans to transE )

-- Imports from agda-algebras -----------------------------------------------------
open import Overture               using ( proj ; projIsOnto ; 𝓞 ; 𝓥 ; Signature ; 𝑆 )
                                   renaming ( IsSurjective to onto )
open import Setoid.Algebras.Basic  using ( Algebra ; _^_ ; ov ; 𝔻[_] ; 𝕌[_])

private variable α ρ ι : Level

open Algebra

    ⨅ 𝒜 is the product of the family 𝒜 : I → Algebra α ρ. Its carrier is the dependent product ∀ i → 𝕌[ 𝒜 i ] of the carriers of the factors; two elements are equal exactly when they agree in every coordinate; and the interpretation of an operation symbol f is the tuple of interpretations of f in the factors, (f ^ ⨅ 𝒜) a i = (f ^ 𝒜 i) (flip a i).

    The types involved in the expression (f ^ ⨅ 𝒜) a i = (f ^ 𝒜 i) (flip a i) are the following:

    I : Type ι
𝒜 : I → Algebra α ρ
a : ArityOf 𝑆 f → (i : I) → 𝕌[ 𝒜 i ]
f : OperationSymbolsOf 𝑆

    The effect of flip a i is to partially apply a to its second argument, i, which results in a map from ArityOf 𝑆 f to 𝕌[ 𝒜 i ] and is exactly the right shaped argument "tuple" to pass to f ^ 𝒜 i.

    Reflexivity, symmetry and transitivity are inherited coordinatewise, and so is the congruence proof for Interp.

    ⨅ : {I : Type ι }(𝒜 : I → Algebra {𝑆 = 𝑆} α ρ) → Algebra {𝑆 = 𝑆} (α ⊔ ι) (ρ ⊔ ι)

Domain (⨅ 𝒜) =
  record  { Carrier = ∀ i → 𝕌[ 𝒜 i ]
          ; _≈_ = λ a b → ∀ i → 𝔻[ 𝒜 i ] ._≈_ (a i) (b i)
          ; isEquivalence =
             record  { refl   = λ i      → reflE   (isEqv 𝔻[ 𝒜 i ])
                     ; sym    = λ x i    → symE    (isEqv 𝔻[ 𝒜 i ])(x i)
                     ; trans  = λ x y i  → transE  (isEqv 𝔻[ 𝒜 i ])(x i)(y i)
                     }
          }

Interp (⨅ 𝒜) ⟨$⟩ (f , a) = λ i → (f ^ 𝒜 i) (flip a i)
cong (Interp (⨅ 𝒜)) (refl , f=g) = λ i → cong  (Interp (𝒜 i)) (refl , flip f=g i)

    Note that both levels of the resulting algebra absorb the level ι of the index type, since the carrier is a function out of I and the equality is an I-indexed conjunction. A product therefore sits at the join of its factors' levels with the level of its index. Correspondingly, the operator P of Setoid.Varieties.Closure, defining the class of products of a class, states membership up to isomorphism, 𝑩 ≅ ⨅ 𝒜, which leaves 𝑩 with its own pair of levels.

    Products of classes of Algebras¶

    A class of algebras is given as a predicate 𝒦 : Pred (Algebra α ρ) _, not as an indexed family, so ⨅ cannot be applied to it directly; and the dependent product over the predicate is not what we want either, since ∀ 𝑨 → 𝑨 ∈ 𝒦 asserts that every algebra belongs to 𝒦.

    The remedy is to take the class itself as the index:

    • ℑ is the type of pairs (𝑨 , p) with p : 𝑨 ∈ 𝒦,
    • 𝔄 sends such a pair to its first component, and
    • class-product is ⨅ 𝔄, the product of all the members of 𝒦.

    Given a proof, p : 𝑨 ∈ 𝒦, that 𝑨 belongs to 𝒦, we view the pair (𝑨 , p) ∈ ℑ as an index over the class, and 𝔄 (𝑨 , p) (which is simply 𝑨) as the projection of the product ⨅ 𝔄 onto the (𝑨 , p)-th component.

    module _ {𝑆 : Signature 𝓞 𝓥} {𝒦 : Pred (Algebra {𝑆 = 𝑆} α ρ) (ov {𝑆 = 𝑆} α)} where

  ℑ : Type (ov {𝑆 = 𝑆} (α ⊔ ρ))
  ℑ = Σ[ 𝑨 ∈ (Algebra {𝑆 = 𝑆} α ρ) ] 𝑨 ∈ 𝒦

  𝔄 : ℑ → Algebra {𝑆 = 𝑆} α ρ
  𝔄 (𝑨 , _) = 𝑨

  class-product : Algebra (ov {𝑆 = 𝑆} (α ⊔ ρ)) (ov {𝑆 = 𝑆} (α ⊔ ρ))
  class-product = ⨅ 𝔄

    One subtlety of indexing by proofs rather than by algebras is that an algebra carrying two membership proofs contributes two identical factors; the result is a product of members of 𝒦 regardless. A variant that indexes by an environment as well appears as ℑ⁺, 𝔄⁺ and ℭ in Setoid.Varieties.HSP.

    Surjectivity of coordinate projections¶

    Suppose I is an index type and 𝒜 : I → Algebra α ρ is an indexed collection of algebras. Let ⨅ 𝒜 be the product algebra defined in the first section of this module. Given i : I, consider the projection of ⨅ 𝒜 onto the i-th coordinate.

    This projection ought to be a surjective map from ⨅ 𝒜 onto 𝒜 i, but this is not so if I is an arbitrary type. Indeed, we need an equality on I, the equality must be decidable, and each factor of the product must be nonempty.

    In the Setoid.Functions.Surjective module we showed how to define a decidable index type in Agda. Here we use this to prove that the projection of a product of algebras over such an index type is surjective.

    module _
  {I   : Type ι}                   -- index type
  {_≟_ : Decidable{A = I} _≡_}     -- with decidable equality
  {𝒜   : I → Algebra {𝑆 = 𝑆} α ρ}  -- indexed collection of algebras
  {𝒜I  : ∀ i → 𝕌[ 𝒜 i ] }         -- each of which is nonempty
  where

  ProjAlgIsOnto : ∀{i} → Σ[ h ∈ (𝕌[ ⨅ 𝒜 ] → 𝕌[ 𝒜 i ]) ] onto h
  ProjAlgIsOnto {i} = (proj _≟_ 𝒜I i) , projIsOnto _≟_ 𝒜I
